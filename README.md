# Personal Introduction Page

A responsive personal introduction page built with semantic HTML and CSS. It
collects my technical focus, competitive-programming profiles, experience at
Vedonyx, selected achievements, and public contact links in one static page.

## Highlights

- About, competitive programming, experience, featured work, and goals
- Direct links to GitHub, Codeforces, LeetCode, LinkedIn, and Unstop
- Reusable cards for projects, achievements, and coding profiles
- Accessible image text and safe external links
- No framework, build step, analytics, or backend

## Run locally

Clone the repository and open `index.html` in a browser. For a local HTTP
server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Structure

```text
.
├── index.html       # page content and sections
├── style.css        # layout, cards, and responsive styling
├── profile.jpg      # profile image
└── *-logo.*         # profile and company marks
```

## Customise

Update the text and links in `index.html`, replace the image assets, and adjust
the colour and spacing rules in `style.css`. No generated files need to be
committed.
