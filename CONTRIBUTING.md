# Contributing

This project is intentionally a small, framework-free personal introduction page.

## Review checklist

- Serve the project with `python -m http.server 8000` and check desktop and mobile widths.
- Keep headings in a logical order and interactive controls keyboard accessible.
- Add useful alternative text to content images; use empty alternative text for decorative images.
- Open external links safely and verify every public profile URL.
- Run the repository's HTML validation workflow before merging.

Prefer focused HTML and CSS changes over new build tools or JavaScript dependencies. Pull requests should include a screenshot when they alter layout or colour.
